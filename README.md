# La Fornarina — Menu digitale

Menu responsive, in italiano, realizzato con HTML, CSS e JavaScript senza framework.

## Avvio

Apri `index.html` nel browser. Le foto sono incorporate nella cartella `assets/` e funzionano anche offline.

## Pubblicazione su GitHub Pages

1. Crea un repository GitHub.
2. Carica **tutti** i file, inclusa la cartella `assets/` (non soltanto `index.html`).
3. Vai in **Settings → Pages** e scegli **Deploy from a branch**, **main**, **/(root)**.

## Personalizzazione

I dati delle pizze sono nell'array `pizzas` in fondo a `index.html`. Puoi modificare nomi, ingredienti, prezzi e allergeni.

Le immagini in `assets/` sono immagini fotorealistiche generate digitalmente, a scopo illustrativo: non raffigurano i prodotti reali della pizzeria.

**Attenzione:** le indicazioni sugli allergeni sono esempi, da confermare in base alle ricette e ai processi effettivamente adottati dalla pizzeria. Nessuna pizza presente in questa demo è indicata come senza glutine.

Il carrello è una demo e non trasmette ordini.
